## 3. HƯỚNG DẪN THỰC HIỆN CHI TIẾT (STEP-BY-STEP)

### Bước 1: Thu thập và Chọn Lọc Subset
1. Không tải toàn bộ 300GB của GenImage. Chỉ chọn tải:
   - Thư mục `midjourney/train/` (chọn ngẫu nhiên 6.000 ảnh real và 6.000 ảnh fake).
   - Thư mục `stable_diffusion_v_1_5/train/` (chọn ngẫu nhiên 6.000 ảnh real và 6.000 ảnh fake).
2. Viết script `data/sample_genimage.py` để trích xuất cân bằng:
```python
import os
import shutil
import random
from pathlib import Path

def sample_subset(src_dir, dst_dir, samples_per_class=6000):
    for cls_name in ["0_real", "1_fake"]:
        src_cls = os.path.join(src_dir, cls_name)
        dst_cls = os.path.join(dst_dir, cls_name)
        os.makedirs(dst_cls, exist_ok=True)
        
        all_files = [f for f in os.listdir(src_cls) if f.lower().endswith(('.png', '.jpg', '.jpeg'))]
        selected = random.sample(all_files, min(samples_per_class, len(all_files)))
        
        print(f"[*] Trích xuất {len(selected)} ảnh từ {src_cls} sang {dst_cls}...")
        for f in selected:
            shutil.copy(os.path.join(src_cls, f), os.path.join(dst_cls, f))

# Áp dụng cho midjourney và sd_v15
sample_subset("/content/raw_genimage/midjourney/train", "/content/sampled/midjourney", 6000)
sample_subset("/content/raw_genimage/sd_v15/train", "/content/sampled/sd_v15", 6000)
```
